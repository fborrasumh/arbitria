ArbitrIA

Panel de revisión por pares con cinco asientos separados por rol, decisión editorial y hoja de ruta de revisión.

Acceso a la API

La clave se guarda solo en este navegador (localStorage). El manuscrito se envía a la API de OpenAI desde tu equipo; no pasa por ningún servidor intermedio.

Manuscrito

Entradas de la re-revisión

La re-revisión exige la hoja de ruta original inmutable, el borrador previo, el manuscrito revisado y el paquete de evidencias. La carta de respuesta se revela solo en la puerta 2B.

Fases

    Pega o carga un manuscrito, guarda tu clave y pulsa Analizar el campo.
    ArbitrIA leerá el trabajo, propondrá cuatro identidades revisoras que podrás editar y luego ejecutará el panel.
